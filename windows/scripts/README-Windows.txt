AI 出差管家（AIGuard）Windows 版
==================================

系统要求：Windows 10 21H2 及以上（推荐 Windows 11），x64 或 ARM64，需要管理员权限安装。

安装
----
1. 把整个文件夹解压到任意位置（不要直接在压缩包里运行）。
2. 先退出 Clash Verge、v2rayN、FlClash 等其他代理/VPN 软件，两个 TUN 会抢路由。
3. 双击 AIGuard.exe，点「安装并启动」，在用户账户控制窗口确认。
   程序会装到 C:\Program Files\AIGuard，设置与日志在 C:\ProgramData\AIGuard。
4. 安装完成后界面会从安装目录重新打开，在「订阅」页粘贴订阅链接导入。

防护行为
--------
- 防火墙规则（WFP）是持久化的：防护服务停止、崩溃或重启电脑后规则依然有效。
  这意味着服务没运行时可能整机断网——这是有意的（宁可断网也不泄漏）。
- 守护开启时会把各网卡 DNS 锁到内核、关闭网卡 IPv6；关闭守护或卸载时恢复。
- 熔断时关闭 AI 程序与浏览器（可在「熔断与安全」页关闭）。

游戏模式
--------
默认手动开启：托盘菜单或「熔断与安全」页。也可以打开「自动检测」，游戏本体运行（启动器不算）
或 UU、雷神等加速器运行时自动进入，退出 1 分钟后恢复。开启后：
- AI 服务一律禁止：Claude、ChatGPT、Cursor、Claude Code 等 AI 程序立即关闭，再打开也会被关掉，并且禁止联网；
  浏览器里的 AI 网站全部拒绝。
- 其余流量直连不走代理，游戏不加代理延迟，UU、雷神等加速器可以正常使用。
识别不到的游戏，在「熔断与安全」页的「额外的游戏程序」里填进程名。

卸载
----
在「熔断与安全」页点「卸载服务」；或在管理员命令行里运行：
  "C:\Program Files\AIGuard\aiguard-service.exe" uninstall          （保留设置与订阅）
  "C:\Program Files\AIGuard\aiguard-service.exe" uninstall --purge  （同时删除设置、订阅与日志）

断网自救
--------
如果卸载不完整导致无法上网，在管理员命令行里运行：
  "C:\Program Files\AIGuard\aiguard-service.exe" firewall-reset
它会停止防护服务并改为手动启动、删除 AIGuard 的全部防火墙规则，并恢复 DNS 与 IPv6 设置。
之后在界面里点「启动防护服务」即可恢复防护（服务会改回随系统启动）。
